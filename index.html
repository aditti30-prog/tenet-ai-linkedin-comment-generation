Tenet is a Chrome extension that helps users draft LinkedIn comments in their own voice. It is an independent tool and is not affiliated with, endorsed by, or connected to LinkedIn or Microsoft.

Information stored on your device

Tenet has no user account. Its settings, API key, voice profile, past-comment samples, writing principles, draft history, active selected post and policy acknowledgement are stored locally in Chrome on the user's device.

Chrome extension storage is local browser storage, not an encrypted secrets vault. Use an API key with only the access and spending limits you need.

Information sent to your AI provider

When you request generation, refinement, voice analysis or a connection test, Tenet sends the information required for that request directly to the provider you selected, currently OpenAI or Anthropic, using your API key.

  • the text of the single LinkedIn post you selected;
  • your drafting or refinement instructions;
  • your saved voice profile and relevant writing principles; and
  • up to five recent past-comment samples when needed to reproduce your writing style.

Your API key is sent only to the selected provider to authenticate the request. Provider processing is governed by the OpenAI Privacy Policy or Anthropic Privacy Policy.

Product performance analytics

After you acknowledge this policy during onboarding, Tenet sends limited product-performance information to a private analytics collector controlled by Tenet's developer. This helps identify failures, monitor reliability and understand AI usage costs.

The analytics may include:

  • a random installation identifier not linked to your name, email address or LinkedIn identity;
  • extension version and feature event;
  • success or failure, latency and technical error code;
  • selected drafting path and refinement controls;
  • AI model family and retry attempt;
  • provider-reported input, cached-input, output, reasoning and cache-write token counts; and
  • estimated API cost.
Analytics never include LinkedIn post text, generated comments, author names, URLs, your name, role, industry, voice profile, past comments, writing principles, API keys or provider credentials.

Analytics records may be retained for up to 365 days. Because the installation identifier is random and is not connected to a customer account or identity, Tenet generally cannot locate analytics records using a person's name or email address.

What Tenet does not do

  • No selling of user information.
  • No use of customer content for advertising or credit decisions.
  • No sending of posts, drafts, voice profiles, writing principles or API keys to the analytics collector.
  • No reading of LinkedIn posts the user did not deliberately select.
  • No automatic posting, commenting, messaging or other LinkedIn action.

Optional feedback

If available, the in-app feedback control opens a separate form. Tenet does not automatically attach post text, drafts, API keys or LinkedIn identity. Only information the user deliberately enters and submits reaches the form owner.

Your controls and retention

Users can inspect, export or delete locally stored Tenet information from the extension's settings. Uninstalling the extension removes its locally stored information according to Chrome's extension-storage behavior. Tenet's analytics collector does not receive LinkedIn posts, generated comments, voice profiles, past-comment samples, writing principles or API keys.

Security

Tenet limits access to the API key to trusted extension contexts and sends provider and analytics requests over HTTPS. No local storage or internet transmission method is completely risk-free. Rotate an API key immediately if you believe it has been exposed.

Children

Tenet is a professional writing tool and is not directed to children under 13.

Changes and contact

This policy may be updated when Tenet's functionality or legal obligations change. Material changes may require acknowledgement of a new policy version. Privacy questions can be submitted through Send feedback in Tenet's Settings or through the public Support page.

Tenet is an independent project and is not affiliated with LinkedIn or Microsoft.

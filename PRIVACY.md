**Privacy Policy

Effective date: 21 September 2026  
Last updated: 21 September 2026**

Tenet is a Chrome extension that helps users draft LinkedIn comments in their own voice. Tenet is an independent tool and is not affiliated with, endorsed by, or connected to LinkedIn or Microsoft.

**1. Information stored on your device**
Tenet has no user account. The following information is stored locally in Chrome on the user's device:
AI provider and model settings;
the user's API key;
role, industry and writing preferences;
voice profile and saved past-comment samples;
writing principles;
draft history;
the active post selected for drafting; and
acknowledgement of the current Terms of Use and Privacy Policy.
Chrome extension storage is local browser storage, not an encrypted secrets vault. Users should use an API key with only the access and spending limits they need.

**2. Information sent to the selected AI provider**
When the user requests generation, refinement, voice analysis or a connection test, Tenet sends the information required for that request directly to the AI provider selected by the user, currently OpenAI or Anthropic. Depending on the request, this may include:
the text of the single LinkedIn post the user selected;
the user's drafting or refinement instructions;
the user's saved voice profile and relevant writing principles; and
up to five recent past-comment samples when needed to reproduce the user's writing style.
The user's API key is sent only to the selected provider to authenticate the request. The provider's handling of this information is governed by its own terms and privacy policy:
OpenAI Privacy Policy
Anthropic Privacy Policy

**3. Product performance analytics**
After the user acknowledges this policy during onboarding, Tenet sends limited product-performance information to a private analytics collector controlled by Tenet's developer. This information helps identify failures, monitor reliability and understand AI usage costs.
The analytics may include:
a randomly generated installation identifier that is not linked to the user's name, email address or LinkedIn identity;
extension version and feature event;
whether an operation succeeded or failed;
latency and a technical error code;
selected drafting path and refinement controls;
AI provider model family;
provider-reported input, cached-input, output, reasoning and cache-write token counts;
retry attempt; and
estimated API cost based on the provider-reported usage.
Analytics do not include:
LinkedIn post text, post URLs or author names;
generated comments or the user's drafting and refinement text;
the user's name, role or industry;
voice profiles, past-comment samples or writing principles;
API keys or provider credentials; or
the user's LinkedIn identity.
Analytics records may be retained for up to 365 days. Because the installation identifier is random and is not connected to a customer account or identity, Tenet generally cannot locate analytics records using a person's name or email address.

**4. What Tenet does not do**
Tenet does not:
sell user information;
use customer content for advertising or credit decisions;
send posts, drafts, voice profiles, writing principles or API keys to Tenet's analytics collector;
read LinkedIn posts the user did not deliberately select; or
post, comment, message or otherwise act on LinkedIn for the user.

**5. Optional feedback**
If the in-app feedback control is available, it opens a separate feedback form. Tenet does not automatically attach post text, drafts, API keys or LinkedIn identity. Information reaches the form owner only when the user deliberately enters and submits it, and is then governed by the form provider's privacy policy.

**6. User controls and retention**
Users can inspect, export or delete locally stored Tenet information from the extension's settings. Uninstalling the extension removes its locally stored information according to Chrome's extension-storage behavior.
Tenet's developer does not receive or retain LinkedIn posts, generated comments, voice profiles, past-comment samples, writing principles or API keys through the analytics collector.

**7. Security**
Tenet limits access to the user's API key to trusted extension contexts and sends provider and analytics requests over HTTPS. No method of local storage or internet transmission is completely risk-free. Users should rotate an API key immediately if they believe it has been exposed.

**8. Children**
Tenet is a professional writing tool and is not directed to children under 13.

**9. Changes to this policy**
This policy may be updated when Tenet's functionality or legal obligations change. The updated date above identifies the latest version. When a material change requires a new acknowledgement, Tenet will present the updated Terms of Use and Privacy Policy before collecting analytics under the new policy version.

**10. Contact**
Privacy questions can be submitted through the extension's Send feedback control or through the public repository's Support page.

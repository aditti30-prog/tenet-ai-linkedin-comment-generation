# Privacy Policy

**Effective date: 31 August 2026**  
**Last updated: 31 August 2026**

Tenet is a Chrome extension that helps users draft LinkedIn comments in their own voice. Tenet is an independent tool and is not affiliated with, endorsed by, or connected to LinkedIn or Microsoft.

## 1. Information stored on your device

Tenet has no user account and does not operate a developer-controlled application server. The following information is stored locally in Chrome on the user's device:

- AI provider and model settings;
- the user's API key;
- role, industry and writing preferences;
- voice profile and saved past-comment samples;
- writing principles;
- draft history; and
- the active post selected for drafting.

Chrome extension storage is local browser storage, not an encrypted secrets vault. Users should use an API key with only the access and spending limits they need.

## 2. Information sent to the selected AI provider

When the user requests generation or refinement, Tenet sends the following directly to the AI provider selected by the user, currently OpenAI or Anthropic:

- the text of the single LinkedIn post the user selected;
- the user's drafting or refinement instructions;
- the user's saved voice profile and relevant writing principles; and
- up to five recent past-comment samples when needed to reproduce the user's writing style.

The user's API key is sent only to the selected provider to authenticate that request. The provider's handling of this information is governed by its own privacy policy:

- [OpenAI Privacy Policy](https://openai.com/policies/privacy-policy)
- [Anthropic Privacy Policy](https://www.anthropic.com/legal/privacy)

## 3. What Tenet does not do

Tenet does not:

- operate analytics or behavioral tracking;
- sell user information;
- send post text, drafts, voice profiles or API keys to the developer;
- read LinkedIn posts the user did not deliberately select;
- post, comment, message or otherwise act on LinkedIn for the user; or
- use customer content for advertising or credit decisions.

## 4. Optional feedback

If the in-app feedback control is available, it opens a separate feedback form. Tenet does not automatically attach post text, drafts, API keys or LinkedIn identity. Information reaches the form owner only when the user deliberately enters and submits it, and is then governed by the form provider's privacy policy.

## 5. User controls and retention

Users can inspect, export or delete locally stored Tenet information from the extension's settings. Uninstalling the extension removes its locally stored information according to Chrome's extension-storage behavior.

Tenet's developer does not retain posts, drafts, profiles or API keys because Tenet does not receive them.

## 6. Security

Tenet limits access to the user's API key to trusted extension contexts and sends provider requests over HTTPS. No method of local storage or internet transmission is completely risk-free. Users should rotate an API key immediately if they believe it has been exposed.

## 7. Children

Tenet is a professional writing tool and is not directed to children under 13.

## 8. Changes to this policy

This policy may be updated when Tenet's functionality or legal obligations change. The updated date above will identify the latest version.

## 9. Contact

Privacy questions can be submitted through the extension's **Send feedback** control or through the public repository's [Support page](SUPPORT.md).

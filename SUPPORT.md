# Support

For product feedback, use **Send feedback** in Tenet's Settings.

For a problem with the public policy documents, open an issue in this repository after it is published.

When reporting a problem:

- describe what you expected and what happened;
- include the Tenet version and Chrome version when relevant;
- include a screenshot only if it contains no confidential information; and
- never include an API key, authentication token, private LinkedIn content or other sensitive information.

Tenet has no access to a user's AI-provider account or billing. Provider-account, credit and API-key issues should be handled through OpenAI or Anthropic support.
